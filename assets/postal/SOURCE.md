# 郵便番号辞書の出典

日本郵便「住所の郵便番号（1レコード1行、UTF-8形式）」の全国データを未改変で同梱しています。

- ダウンロード: 2026-10-07
- 掲載更新日: 2026-09-30
- データ: https://www.post.japanpost.jp/service/search/zipcode/download/utf/zip/utf_ken_all.zip
- 説明・再配布条件: https://www.post.japanpost.jp/service/search/zipcode/download/utf-readme.html
- SHA-256: `444881769a631d2c36c644fc041e5ce62fe65d204ff498a601641ba1e66b5955`

日本郵便は郵便番号データについて著作権を主張せず、再配布を認めています。一般町域の辞書であり、大口事業所の個別番号は含まれません。

この辞書は全国の公開町域データで、実名簿の個人情報は含めていません。アプリはZIPをローカルで検索し、郵便番号・氏名・住所を外部サービスへ送信しません。

括弧内の住所範囲条件は候補に表示し、自動入力は括弧より前の町域までです。「以下に掲載がない場合」「市町村一円」「市町村の次に番地がくる場合」は町域名として住所に挿入しません。番地・建物・対象範囲は利用者が確認してください。

更新時は上記公式URLのZIPをこのファイルと同じフォルダーの `utf_ken_all.zip` に保存し、ハッシュ・掲載更新日を確認してアプリを再起動してください。全国データの更新のためだけにネットワークを使い、住所検索時は使いません。
